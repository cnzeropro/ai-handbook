# TS 4.x 及以下（遗留环境）规范

> 适用：TS 4.x 及以下遗留项目。仅在维护既有代码或项目明确要求时使用；新项目一律 TS 5.x（见 `ts5.md`）。同一项目保持编译器大版本与写法一致，不混用。

## 一、写法基线

- **实验性 decorators**：4.x 的 decorators 依赖 `experimentalDecorators` 编译项（5.0 已标准化）——遗留项目保持开启，不混用两种 decorators 语法
- **无 satisfies**（4.9 才引入）：类型校验场景退回 `as` 断言或显式类型标注，注意 `as` 丢失字面量类型的代价
- **无 const 类型参数**（5.0 才引入）：字面量推导在调用处补 `as const`
- **无推断类型谓词**（5.5 才引入）：过滤收窄必须手写 `(x): x is T => …` 注解
- **strict 等级**：遗留项目常未全开——维护时保持项目既有 strict 等级，**不顺手开启**（可能瞬间爆出海量报错）；开启 strict 作为独立升级任务

## 二、遗留代码最小侵入

- 与项目既有写法保持一致，不顺手做语法升级（如 satisfies 替代 as），避免无关 diff
- 遗留库中的新文件与项目 TS 版本能力保持一致
- 升级路径：先升编译器大版本（4.x → 5.x，破坏面小），再按 `ts5.md` 采用新特性；TS 6/7 迁移以官方迁移指南为准
