# ES2023~2025 写法规约

> 本文件为 ES2023~2025 的**写法选择规约**（推荐写法 vs 旧写法 + 踩坑原因），不是特性介绍——语法细节以 MDN/官网为准。须与 `general-quality.md` 及此前版本分册配合使用。

## 目录

- 一、ES2023 写法规约 —— findLast、不可变数组方法
- 二、ES2024 写法规约 —— withResolvers、groupBy、Well-Formed
- 三、ES2025 写法规约 —— Set 组合方法、Iterator 辅助、Import attributes

## 一、ES2023

### 1. findLast / findLastIndex 替代 reverse + find

倒转查找会多一次数组拷贝，且 `reverse()` 会变异原数组（共享状态场景是事故源）：

```js
// ❌ 多余拷贝；reverse 还变异原数组
const lastActive = [...users].reverse().find((u) => u.active);

// ✅
const lastActive = users.findLast((u) => u.active);
```

### 2. toSorted / toReversed / toSpliced / with 替代"先拷贝再变更"

"拷贝 + 变异"两步写法漏掉拷贝一步就会变异共享状态（React state、模块级缓存的高危场景）：

```js
// ❌ 两步写法，漏拷贝即变异
const sorted = [...models].sort((a, b) => a.age - b.age);

// ✅ 一步返回新数组
const sorted = models.toSorted((a, b) => a.age - b.age);
const replaced = models.with(0, newModel);
```

## 二、ES2024

### 1. Promise.withResolvers 替代手工 new Promise 包装

手工管理 `resolve` / `reject` 容易漏调用（promise 永久悬挂）：

```js
// ❌ 某分支漏调用 resolve/reject 即悬挂
let resolve, reject;
const promise = new Promise((res, rej) => {
  resolve = res;
  reject = rej;
});

// ✅
const { promise, resolve, reject } = Promise.withResolvers();
```

### 2. Object.groupBy / Map.groupBy 替代 reduce 手工分组

reduce 手工分组是高频 bug 点：初始值漏写（acc 首轮为 undefined）、忘记返回 acc：

```js
// ❌ 三处都可能写错
const byDept = users.reduce((acc, u) => {
  (acc[u.dept] ??= []).push(u);
  return acc;
}, {});

// ✅
const byDept = Object.groupBy(users, (u) => u.dept);
```

### 3. toWellFormed 防孤立代理项报错

含孤立代理项的字符串进 `encodeURIComponent` 会抛 URIError（用户输入常见）：

```js
// ❌
encodeURIComponent(userInput);

// ✅
encodeURIComponent(userInput.toWellFormed());
```

## 三、ES2025

### 1. Set 组合方法替代 filter + has 循环

`filter + has` 是 O(n×m) 双重遍历，且语义要读代码才知；组合方法 O(n) 且见名知意：

```js
// ❌
const both = [...a].filter((x) => b.has(x));

// ✅
const both = a.union(b);
const onlyA = a.difference(b);
```

### 2. Iterator 辅助方法替代中间数组

filter/map 链每步物化一个中间数组（大数据集内存与耗时翻倍）；迭代器辅助惰性执行：

```js
// ❌ 三个中间数组
const top = all.filter((x) => x.active).map((x) => x.name).slice(0, 10);

// ✅ 惰性，无中间数组
const top = all.values()
  .filter((x) => x.active)
  .map((x) => x.name)
  .take(10)
  .toArray();
```

### 3. Import attributes 声明 JSON 类型

JSON 模块必须显式声明类型；旧的 `assert` 语法已废弃（继续用会在新编译目标上报错）：

```js
// ❌ 已废弃
import config from './config.json' assert { type: 'json' };

// ✅
import config from './config.json' with { type: 'json' };
```
