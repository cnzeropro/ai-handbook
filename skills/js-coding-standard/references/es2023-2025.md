# ES2023~2025 规范（当前在用版本）

> 本文件为 **ES2023 ~ ES2025** 版本增量约定，须与版本通用的 `general-quality.md` 及此前版本分册（`es2015.md` / `es2016-2019.md` / `es2020-2022.md`）配合使用。

## 一、ES2023

### 1. 不可变数组方法

`toSorted` / `toReversed` / `toSpliced` / `with` 返回**新数组**，替代"先拷贝再变更"的两步写法（不可变更新原则见 `general-quality.md`）：

```js
// ❌ 拷贝再排序
const sorted = [...models].sort((a, b) => a.age - b.age);

// ✅
const sorted = models.toSorted((a, b) => a.age - b.age);
const replaced = models.with(0, newModel);
```

### 2. findLast / findLastIndex

从尾部查找，替代 `reverse()` + `find` 或手工倒序循环：

```js
// ❌
const lastActive = [...users].reverse().find((u) => u.active);

// ✅
const lastActive = users.findLast((u) => u.active);
const lastIndex = users.findLastIndex((u) => u.active);
```

## 二、ES2024

### 1. Promise.withResolvers

解构出 `resolve` / `reject` / `promise`，替代手工 new Promise 包装：

```js
// ❌
let resolve, reject;
const promise = new Promise((res, rej) => {
  resolve = res;
  reject = rej;
});

// ✅
const { promise, resolve, reject } = Promise.withResolvers();
```

### 2. Object.groupBy / Map.groupBy

按 key 分组，替代 `reduce` 手工分组：

```js
// ❌
const byDept = users.reduce((acc, u) => {
  (acc[u.dept] ??= []).push(u);
  return acc;
}, {});

// ✅
const byDept = Object.groupBy(users, (u) => u.dept);
```

### 3. String 原型 isWellFormed / toWellFormed

校验与修复孤立代理项（避免 `encodeURIComponent` 抛 URIError）：

```js
// ✅
if (!input.isWellFormed()) {
  input = input.toWellFormed();
}
```

## 三、ES2025

### 1. Set 组合方法

`union` / `intersection` / `difference` / `symmetricDifference` / `isSubsetOf` / `isSupersetOf` / `isDisjointFrom`，替代手工循环集合运算：

```js
// ❌
const both = [...a].filter((x) => b.has(x));

// ✅
const both = a.union(b);
const onlyA = a.difference(b);
```

### 2. Iterator 辅助方法

迭代器上的 `map` / `filter` / `take` / `drop` / `flatMap` / `reduce` / `toArray`——惰性求值，不物化中间数组：

```js
// ✅ 大数据集分页取前 N 条，中间结果不落数组
const top = fetchAllIter()
  .filter((item) => item.active)
  .map((item) => item.name)
  .take(10)
  .toArray();
```

### 3. Import attributes

导入 JSON 等非 JS 模块时显式声明类型（替代已废弃的 assert 语法）：

```js
import config from './config.json' with { type: 'json' };
```
