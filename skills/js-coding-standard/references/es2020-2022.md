# ES2020 ~ ES2022 增量规范

> 适用：项目构建目标 / 运行时达到对应版本时使用。新项目无特殊约束时，建议以 ES2020+ 为基线。高写法规约覆盖低版本，须同时适用 `es2015.md`、`es2016-2019.md`。

## 一、ES2020

### 1. 可选链 ?.

安全访问深层属性，中间层为 `null` / `undefined` 时短路返回 `undefined`：

```js
// ❌ 逐层判空
const city = user && user.address && user.address.city;

// ✅
const city = user?.address?.city;
```

注意：`?.` 只短路 `null` / `undefined`，不要滥用（确定存在时直接访问）；避免 `no-unsafe-optional-chaining`（对结果继续调用/运算前确认类型）。

### 2. 空值合并 ??

仅在左侧为 `null` / `undefined` 时取右侧值；`||` 会把 `0`、`''`、`false` 一并当作“空”（Airbnb 15.9）：

```js
// ❌ count 为 0 时会错误地取到默认值
const count = input.count || 10;

// ✅
const count = input.count ?? 10;
```

### 3. 其他

- `Promise.allSettled`：并发任务需要全部结果（无论成败）时使用；全部必须成功才继续的场景仍用 `Promise.all`
- 动态 `import()`：按需加载模块
- `globalThis`：跨环境访问全局对象，替代 `window` / `global` 判断

## 二、ES2021

### 1. String.prototype.replaceAll

替换全部匹配，替代 `replace` + 全局正则：

```js
// ❌
const str = raw.replace(/-/g, '_');

// ✅
const str = raw.replaceAll('-', '_');
```

### 2. 逻辑赋值运算符

`&&=` / `||=` / `??=`：按条件赋值，配合 `??` 语义最常用：

```js
// ❌
if (obj.timeout === undefined) {
  obj.timeout = 3000;
}

// ✅
obj.timeout ??= 3000;
```

### 3. Promise.any

任一成功即 resolve（全部失败才 reject），与 `allSettled`、`all`、`race` 按语义选用。

## 三、ES2022

### 1. Object.hasOwn

替代 `Object.prototype.hasOwnProperty.call`（Airbnb 3.7）：

```js
// ❌
object.hasOwnProperty(key);
Object.prototype.hasOwnProperty.call(object, key);

// ✅
Object.hasOwn(object, key);
```

### 2. 类私有字段

真私有成员，替代下划线前缀约定：

```js
// ❌ 下划线"私有"实为公开属性
class Person {
  constructor() {
    this._firstName = 'Panda';
  }
}

// ✅
class Person {
  #firstName = 'Panda';

  getFirstName() {
    return this.#firstName;
  }
}
```

### 3. 其他

- 顶层 `await`：仅用于模块入口（ESM），副作用最小化，不在库文件中滥用
- `Array.prototype.at`：负索引取值 `arr.at(-1)`，替代 `arr[arr.length - 1]`
