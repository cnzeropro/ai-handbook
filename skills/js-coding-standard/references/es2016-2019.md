# ES2016 ~ ES2019 增量规范

> 适用：项目构建目标达到对应版本时使用。高写法规约覆盖低版本：目标为 ES2019 时，同时适用 ES2015 基线（见 `es2015.md`）与本文件全部规范。

## 一、ES2016：指数运算符

使用 `**` 替代 `Math.pow`（Airbnb 12.3）：

```js
// ❌
const binary = Math.pow(2, 10);

// ✅
const binary = 2 ** 10;
```

## 二、ES2017：async/await

async/await 优先于 Promise 链，Promise 优先于回调：回调嵌套深、错误处理分散；async/await 可用命令式写法表达异步流程（clean-code Concurrency）：

```js
// ❌ 回调嵌套
getData((err, data) => {
  if (err) {
    console.error(err);
    return;
  }
  saveData(data, (saveErr) => {
    if (saveErr) {
      console.error(saveErr);
    }
  });
});

// 可接受：Promise 链
getData()
  .then((data) => saveData(data))
  .catch((error) => console.error(error));

// ✅
async function load() {
  try {
    const data = await getData();
    await saveData(data);
  } catch (error) {
    console.error(error);
  }
}
```

> 不吞错误的原则（catch 必须处理）见 `general-quality.md`“异步错误处理”。

## 三、ES2018：对象展开与剩余属性

优先使用对象展开浅拷贝生成新对象，替代 `Object.assign`（Airbnb 3.8；ESLint `prefer-object-spread`）：

```js
// ❌ 修改原对象
const original = { a: 1, b: 2 };
const copy = Object.assign(original, { c: 3 });

// 可接受：不修改原对象
const copy = Object.assign({}, original, { c: 3 });

// ✅
const copy = { ...original, c: 3 };

// 剩余属性：剔除字段生成新对象
const { a, ...noA } = copy;
```

对应地，“对象静态化”规则的扩展写法（见 `es2015.md`“四、对象”）在 ES2018+ 使用 `{ ...a, x: 3 }`。

## 四、ES2019：数组与对象新方法

- `Array.prototype.flat` / `flatMap`：替代 `reduce` + `concat` 的手动展平
- `Object.fromEntries`：键值对列表转对象（与 `Object.entries` 互逆）
- 可选 catch 绑定：不需要错误对象时 `catch {}`，省略未使用的参数

```js
// ✅
const nested = [1, [2, [3]]];
const flat = nested.flat(Infinity);

const obj = Object.fromEntries([['a', 1], ['b', 2]]);

try {
  mayThrow();
} catch {
  // 不需要错误对象时省略绑定
}
```
